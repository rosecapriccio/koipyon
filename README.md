# プレミアムポップアップ（シャニマス ファンゲーム）

『アイドルマスター シャニマス Colors』をモチーフにした、ブラウザで手軽に遊べる2Dジャンプアクションミニゲームです。
ミリメートル（mm）単位の精密なジャンプ感覚を競い、オンラインで他のプロデューサーたちとスコアを競い合うことができます。

👉 [今すぐブラウザで遊ぶ](https://[あなたのユーザー名].github.io/[リポジトリ名]/)

---

## 🎮 ゲーム概要

プレイヤーはキャラクターを操作し、タイミングよくジャンプしてより高いスコア（mm）を目指します。
シンプルながらも奥が深く、つい何度も挑戦したくなるカジュアルゲームです。

### 主な機能
- **直感的な操作性**: PC（キーボード/マウス）およびスマートフォン（タップ操作）の両対応。
- **オンラインランキング**: 上位15名のハイスコアをリアルタイムに集計・表示。

## 🚀 技術的なこだわり・実装のポイント

### 1. クライアント・サーバー間の安全なデータ連携
オンラインランキングのデータ管理には **Firebase（Cloud Firestore）** を採用。
セキュリティ面を考慮し、データベースへの不正アクセスを防ぐ **Firestore Security Rules** を適切に設定しています。また、APIキーをはじめとする認証情報は、ローカル開発時には `.env` で環境変数として管理し、GitHub上に秘匿情報を流出させない設計を徹底しています。

### 2. Webpackを用いた環境変数の動的注入
Viteなどの内蔵機能に頼らず、純粋な **Webpack 5** 環境において `.env` の環境変数をブラウザ環境に注入する仕組みを構築しました。
`webpack.DefinePlugin` と Node.js のファイルシステム（`fs`）を活用し、ビルド時に安全に環境変数を埋め込むコードベースの構成管理を行っています。

### 3. 完全レスポンス・マルチデバイス対応
PCのブラウザ環境だけでなく、スマートフォンの縦画面・横画面でもUIやキャンバスサイズが自動で最適化（リサイズ）されるよう、Phaser3のScale Managerを用いたレスポンス対応を行っています。

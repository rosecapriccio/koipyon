## 🎮 ゲーム概要

プレイヤーはキャラクターを操作し、タイミングよくジャンプしてより高いスコア（mm）を目指します。  
高度が上がるにつれて、ステージが難しくなっていく仕様です。  

**[ゲームプレイはこちらから　公開URL](https://rosecapriccio.github.io/koipyon/)**

### 主な機能
- **操作**: PC（キーボード/マウス）およびスマートフォン（タップ操作）の両対応。
- **オンラインランキング**: 上位15名のハイスコアをリアルタイムに集計・表示。オンラインで他のプロデューサーたちとスコアを競い合うことができます。
- **高難易度モード**: ステージの足場が極小＋高速移動するモード。

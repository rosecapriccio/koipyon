## 🎮 ゲーム概要

プレイヤーはキャラクターを操作し、タイミングよくジャンプしてより高いスコア（mm）を目指します。
高度が上がるにつれて、ステージが難しくなっていく仕様です。

👉 [ブラウザで遊ぶ](一時的に非公開)

### 主な機能
- **直感的な操作性**: PC（キーボード/マウス）およびスマートフォン（タップ操作）の両対応。
- **オンラインランキング**: 上位15名のハイスコアをリアルタイムに集計・表示。
